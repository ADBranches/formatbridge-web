- **Category:** Functional

Description:

Description:
As a website visitor, I want to be able to navigate to the home page, join page or directory page on all pages with ease so I can find the information I am seeking.

# Phase 7 — Generate Requirements Report

## Objective
Export the final report from Squash for Canvas submission.

## Steps
1. Click **Reporting** on the left sidebar.
2. Select the **Teton CoC** project.
3. Add a new report.
4. Name the report: `All Requirements`.
5. Use template: `270-Requirements.template.docx`.
6. Select the entire `Teton CoC` project as the report perimeter.
7. Set sort order to `Positional`.
8. Check: `Print only the latest requirement version`.
9. Check: `Print folder information`.
10. Leave unchecked: `Print associated test cases`.
11. Leave unchecked: `Print attached requirements`.
12. Save/Add the report.
13. Download the report.

## Files/Directories Created or Updated
Downloaded report file, likely in:

```bash
~/Downloads
```

Possible generated file example:

```text
Requirements report-YYYYMMDDHHMM.docx
```

## Completion Check
- Report downloads successfully as `.docx`.
- Report includes all 3 folders.
- Report includes all 17 requirements.
